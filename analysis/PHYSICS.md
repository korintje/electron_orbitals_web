# Electron Orbitals が「何を」表示しているか — 物理的解釈

検証スクリプト: `analysis/verify/verify_integrals.py`(シェーダの求積を CPU で再現し直接積分と比較)、
`analysis/verify/phase_colors.py`(位相 → 色の対応)。

## 1. 波動関数
水素原子 (Z = 1)、原子単位 (長さ a₀ ≈ 0.0529 nm、エネルギー E_h = 27.2 eV)。

ψ_nlm(r, θ, φ) = R_nl(r) · Θ_l^{|m|}(θ) · Φ_m(φ)

| 部分 | 実装 | 規格化 |
|---|---|---|
| R_nl | (2/n)^{3/2} √((n−l−1)!/(2n (n+l)!)) e^{−r/n} (2r/n)^l L_{n−l−1}^{2l+1}(2r/n) | ∫R² r² dr = 1 |
| Θ_l^{|m|} | √((2l+1)/2 · (l−|m|)!/(l+|m|)!) P_l^{|m|}(cos θ) | ∫Θ² sin θ dθ = 1 |
| Φ_m (ℂ) | e^{imφ}/√(2π) | ∫\|Φ\|² dφ = 1 |
| Φ_m (ℝ) | m>0: √2 cos(mφ)/√(2π)、m<0: √2 sin(mφ)/√(2π)、m=0: 1/√(2π) | 同上 |

- 量子数: **N = 主量子数 n**(1–12)、**l = 方位量子数**(0…n−1)、**m = 磁気量子数**(−l…l)。
- Condon–Shortley 位相 (−1)^m は**含まない**。また ℝ の m<0 は sin(mφ) = −sin(|m|φ) なので、教科書の p_y, d_xy 等と**符号が逆**になる場合がある。確率密度には影響しないが、実軌道の色(符号)は入れ替わる。
- ℂ 基底: L² と L_z の同時固有状態(L_z = mħ が確定)。ℝ 基底: ±m を組み合わせた実関数(化学で使う p_x, d_xy …)。ℝ では m は確定せず |m| のみ意味を持つ(表示も ±|m|)。

## 2. 1 画素の値 = 視線に沿った積分(投影像)
3D の断面でも等値面でもなく、**視線上の積分**を表示している(X 線写真に近い)。
各画素の視線 s について、半径 R_max の球内で:

| 出力 | 量 |
|---|---|
| mono | N = ∫ \|ψ\|² ds |
| color.z | N = ∫ \|ψ\|² ds(mono と同じ量) |
| color.xy | P = ∫ \|ψ\| ψ ds = ∫ \|ψ\|² e^{i arg ψ} ds(\|ψ\|² 重みの位相フェーザ和) |

数値検証 (n,l,m) = (4,2,1), (3,2,−2), (5,3,2) で、シェーダ求積は直接積分と 5–10% 以内で一致(低次 Gauss 求積による近似誤差)、位相の向きも一致。

→ **モノクロモードは「存在確率密度 |ψ|²」の(視線方向)投影であり、二乗されている**。
求積の重み関数自体が R(r)² になっており(`QuadratureGenerator`)、シェーダは角度部分 |Y|² を掛けるだけ。
さらに、カラーモードの**明るさはモノクロと全く同じ量・同じ写像**で、カラーは「確率密度 (明るさ) + 位相 (色相)」の同時表示。

R_max: 動径分布の外側の裾が 10⁻⁴ になる半径 (`MaximumRadiusGenerator`、重み r¹ で計算)。

## 3. 明るさの写像(非線形・軌道ごとに正規化)
I = 1 − exp(−b N)、b = R_max(n,l)² / 2 → 表示輝度 Y = I/2(線形)→ sRGB ガンマ。
- 飽和型の非線形写像。N の目盛りは N = −ln(1 − I)/b で逆算できる(単位 a₀⁻²)。
- **b が軌道ごとに違う**ため、異なる軌道間で明るさの絶対比較はできない。

## 4. 色の写像(位相)
CIE 1976 (u′, v′) 色度図上で、D65 白色点を中心に半径 0.06 の円周上を位相で回す**等輝度の色相環**。

- 色相 = arg P(視線上の |ψ|² 重み平均位相)。時間回転後の位相 0° = ピンク、90° = 黄、180° = 青緑、270° = 薄紫。
- 彩度 = |P|/N(位相の揃い具合)。視線上で位相が打ち消し合うと白っぽくなる。
- 色が sRGB 範囲外になると黒になる(明るい領域の一部)。
- 色覚補正モード: 混同線に直交する 1 軸に射影するため、位相は ±方向の 2 色に縮退する。

ℝ 軌道では ψ が実数なので位相は 0 か π の 2 色(= 波動関数の符号 +/−)。

## 5. 時間変化
ψ(t) = ψ e^{−iE_n t/ħ}、E_n = −13.6 eV / n²(電離極限をゼロとする)。
- 単一の固有状態なので**全体の位相が回るだけ**(|ψ|² は時間変化しない = 定常状態)。
- アプリでは周期 n² 秒(実際の周期 h/|E_n| = 3.04×10⁻¹⁶ n² 秒 → 約 3.3×10¹⁵ 倍に減速)。
- 表示位相 = arg ψ + |E_n| t/ħ。ℂ 軌道 (m > 0) では等位相面が φ 方向に −|E_n|/(mħ) で回る。
  一方、確率流密度 j_φ = ħ m |ψ|²/(μ r sin θ) は +φ 向き。つまりこの色の流れる向きは**エネルギー原点の取り方に依存する位相速度**であり、確率流とは逆向きになる(原作ヘルプの「色の動く向き = 電子の運動の向き」は厳密には正しくない)。
- ℝ 軌道でも色は回るが、これは観測不能な全体位相であり、+/− の 2 色が色相環上を対蹠的に回るだけ。

## 6. 教育上の主な分かりにくさ(UI 改善の対象)
1. 3 つの数字が n, l, m であることが表示されない。
2. 色・明るさの凡例(カラーバー)がない。
3. ℂ/ℝ が「複素関数/実関数の基底」であることが表示されない。
4. モノクロ = 確率密度表示だと分からない(アイコンが「パレット/白黒」)。
5. 表示が投影(積分)であること、明るさが非線形・軌道ごと正規化であることが分からない。
6. スケール(軸の長さ = 0.75 R_max a₀)が分からない。
7. エネルギー・節の数などの物理量が表示されない。
8. 時間変化(色の回転)が何を意味するか、再生ボタンが何をするか分からない。

## 7. 断面表示モード(Web 版で追加)
- 平面 x·n̂ = d(n̂ = 視線方向、d = スライダー)上で ψ を直接評価する (`src/shaders/section.frag`)。
- 明るさ I = 1 − exp(−k|ψ|²)、k = G / max|ψ|²(G = 10 × ゲインスライダー、max は軌道ごとに CPU で計算)。凡例の目盛りは |ψ|² [a₀⁻³]。
- 出力形式は積分器と同じなので、色(位相)・時間回転・色覚補正は ScreenDrawer がそのまま処理する。位相は平均化されないため、彩度は常に最大。
- 節面は ψ = 0 の暗い線として直接見える(例: 4d_xz の zx 断面で x = 0, z = 0 の十字と動径節の円)。

## 8. 明るさの共通スケール・色の流れの向き(Web 版で追加)
- 明るさの基準「全軌道共通」(既定値は「軌道ごと」): 投影では b = G · R_max(2,1)²/2(2p の値)、断面では k = 10G / max|ψ_2pz|² を全軌道で使う。凡例の目盛りが軌道によらず同じになり、明るさを軌道間で比較できる。G は「明るさ」スライダー(両モード共通、×0.01–×100)。
- (一時的に実装した「色の流れ」の反転オプションは削除した。単一の定常状態の全体位相の回転方向はエネルギー基準の取り方に依存するだけで観測できず、切り替えても物理的な情報が増えないうえ、「色の動き = 電子の運動」という誤解を強めるため。)

## 9. 確率流の矢印(Web 版で一時実装 → UI から一旦削除)
- 矢印表示はコミット b4aa1f9 で実装し、その後 UI から一旦取り除いた(`src/current.ts` は git 履歴から復元可能)。ⓘ パネルの「確率流」の説明文は残している。
- j = (ħ/μ) Im(ψ*∇ψ) = (mħ/μ) |ψ|²/(r sin θ) φ̂ = m R²Θ²/(2π ρ²) · (−y, x, 0)(原子単位)。基準の取り方に依存しない観測量で、定常状態では時間変化しない。
- ℝ 軌道(±m の定在波)と m = 0 では j = 0。m ≠ 0 の ℂ 軌道では z 軸の周りを回り、+z から見て m > 0 で反時計回り、m < 0 で時計回り(L_z = mħ と対応)。
- 断面表示: 平面上の j。面内成分を矢印、法線成分が優勢な点は ⊙(手前向き)/⊗(奥向き)。長さは全空間での max|j| で規格化(節面では矢印が消える)。
- 投影表示: 視線方向の積分 ∫ j ds の画面内成分。長さは画面内の最大値で規格化。
- 検証: 2p₊₁ / 2p₋₁ の xy 断面(+z から)で反時計回り/時計回り、4d₁ の xy 平面(節面)で矢印なし、zx 断面で x<0 側 ⊙・x>0 側 ⊗。

## 10. 動径部分のプロット(Web 版で追加、ⓘ パネル「動径部分」)
- `src/radialplot.ts`: R_nl(r)(動径波動関数)、R_nl(r)²、D(r) = r² R_nl(r)²(動径分布関数)を r/a₀ = 0 … R_max で縦に 3 段描画(SVG)。
- 名称: R(r) は「動径波動関数」、r²R² が「動径分布関数」(∫D dr = 1)。R² には定着した名前がないので「方向を固定したときの 1 点あたりの確率密度」と説明している。D(r) の記号は、直上の式のルジャンドル関数 P_l^{|m|} との混同を避けるため P(r) ではなく D(r) とした。
- 動径節(Laguerre 多項式の正の零点)を破線、⟨r⟩ を点線、最確半径 r_mp(D の最大)を点で表示。D の山の数は n − l、l = n − 1 では r_mp = n² a₀。
- 説明の分担: ⓘ パネル(この軌道について)は表示中の軌道に固有の値・事実だけを書き(節の位置、R² の最大位置、r_mp、⟨r⟩、山の数など)、軌道によらない一般的な説明(各グラフの定義・意味、なぜその距離か、貫入、画面の読み方)はヘルプに置く。ⓘ パネルからはリンク(`a.help-link`)でヘルプの該当節(`#help-radial`, `#help-read`)に飛ぶ。

## 11. 用語(Web 版の UI 表記)
- ℂ / ℝ ボタン: 「複素軌道」(補足: z 軸周りの回転(L_z)を見る。色の空間的な巻きが L_z を表し、|L| は表さないため z 軸と明記)/「実軌道」(補足: 形と向きを見る)。補足は初見で分かるよう、性質(L_z 確定など)ではなく何を見るための軌道かを一言で書く。「結合の向き」は孤立原子には結合がなく、実際の結合角(H₂O 104.5° など)とも一致しないため使わない。ℂ / ℝ は数の集合の記号で、切り替えているのは基底(L_z 固有関数か、±m を足し引きした実関数か)なので、記号はアイコンとしてだけ残し、言葉を主表記にした。m = 0 では両者は同じ関数なので、補足に「m = 0 では同じ関数」と出す。
- 色モード: 複素軌道では「位相＋確率密度」、実軌道では「符号＋確率密度」、白黒は「確率密度のみ」。凡例も実軌道では「色: ψ の符号」。
- 投影の明るさは「視線に沿って積分した確率密度」N = ∫|ψ|² ds、断面の明るさは確率密度 |ψ|²。投影の色は ∫|ψ|ψ ds の位相(実軌道では符号)。詳細はヘルプ「表示している値」「複素軌道と実軌道」。
